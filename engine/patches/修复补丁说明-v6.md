# GameBox v6.0 引擎补丁说明 — 管线缓存防崩（0x80000003 根因修复）

## 一、这个补丁修什么

**用户报告**：v5.1 启动游戏直接闪退打不开，退出码 2147483651（0x80000003）。

**引擎日志证据**（`vulkan错误日志.txt` 尾部）：

```
[Render.Vulkan] vk_pipeline_serialization.cpp:288 LoadPipelineStage:
  Cached permutation 5 of vs_c145b4b2 conflicts with index 0, skipping preload
[Debug] <Critical> vk_pipeline_serialization.cpp:238 LoadGraphicsPipeline:
  Assertion Failed!
[GameBox] 进程退出，code=2147483651(0x80000003)
```

注意：这次 GPU 选卡已经正确（日志可见 `GPU_Model: NVIDIA GeForce GTX 960M /
Vulkan 1.4.312`，v5 的选卡修复已生效）—— 崩溃点在**管线缓存装载**。

## 二、根因链（缓存归档字节级解析实证）

1. 用户 `config.toml` 里 `pipelineCacheArchive = true`（v4 引入的归档模式）→
   引擎启动时读 `user/cache/CUSA15006.zip` 单文件归档。
2. **实测该归档含 1468 个条目，其中 446 组【同名重复条目】**（892 个文件每个
   出现 2 次）：归档是两个引擎世代的缓存合并/追加写档产生的 —— 前一世代
   （原版/CVN 引擎：键版本 4、着色器元数据 binary_version=5）与后一世代
   （补丁引擎：键版本 3、binary_version=3）各写了一份同名条目。
3. 引擎 `WarmUp()` → `ForEachBlob` 按 zip 条目顺序遍历全部 `.key` 条目
   **不查同名** → 同一个管线键被反序列化两次 → `try_emplace` 命中已有键 →
   `ASSERT(is_new)` 失败 → `abort()` → 进程退出码 0x80000003。
4. 伴随的 "Cached permutation N of vs_xxx conflicts with index 0" 警告正是
   「缓存里混着多于一个世代」的直接证据（引擎源码注释原文如此）。

## 三、补丁内容（1 文件 56 行）

`src/video_core/renderer_vulkan/vk_pipeline_serialization.cpp` 两处加固：

### ① LoadGraphicsPipeline（238 行断言 → 优雅跳过）

```cpp
const auto [it, is_new] = graphics_pipelines.try_emplace(graphics_key);
if (!is_new) [[unlikely]] {
    LOG_WARNING(Render_Vulkan, "Duplicate graphics pipeline entry in cache ...");
    infos.fill(nullptr); modules.fill(nullptr); fetch_shader.reset();
    return false;   // 该条管线运行时按需重编，绝不中止进程
}
```

### ② LoadComputePipeline（同类隐患一并根治）

同样的 `ASSERT(is_new)` → LOG_WARNING + 跳过（键值记入日志，可诊断）。

**原则**：管线缓存只是加速器。缓存数据损坏、混杂、版本错位时，正确行为是
降级为跳过该条并按需重编译 —— **任何缓存状态都不该中止模拟器进程**。

## 四、与前端 v6.0 修复的双保险

| 层 | 修复 | 生效方式 |
|----|------|----------|
| 前端 v6.0（立即生效，免重编译） | 启动迁移 `migrate60` 缓存体检：归档字节级去重重建（保留最近世代条目，备份 .bak-v6）+ ini 键位令牌再规范化 + 体检报告记录 | 解压 GameBox-v6.0.zip 覆盖即生效 |
| 引擎 v6（本补丁，需编译） | 重复条目 → 警告+跳过；不再 ASSERT 中止 | GitHub 云编译 / 本机编译后装回 |

即使不编译引擎补丁，仅前端去重后的干净归档也不会再触发断言；引擎补丁保证
未来任何缓存损坏（杀毒软件半路拦截、断电、多引擎共用）也绝不闪退。

## 五、验证方法（装回后 30 秒）

1. GameBox 启动游戏 → 主界面日志应出现：
   `v6.0 一次性迁移【缓存防崩+键位修复】：CUSA15006.zip 归档体检：发现并去除 N 个同名重复条目…`
   （首次迁移时；干净机器上显示"检查通过"）
2. 游戏正常进入标题画面，不再闪退（退出码 0x80000003 消失）。
3. 引擎日志（user/logs/shadps4.log）里 `Preloaded N pipelines` 数字正常。
4. 设置 → 体检 → 诊断记录里可见缓存体检条目。
