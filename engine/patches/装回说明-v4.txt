 GameBox v4.0 — 补丁引擎装回说明 v4（重要：本页就是"未找到"的答案）
═══════════════════════════════════════════════════════════════

【为什么之前显示"未找到"（前端源码实证，不是猜的）】

GameBox v4.0 前端体检页检测的是这两处（main.js enginePatchState 函数原文）：

  ① 补丁引擎编译产物 → <GameBox根>\build-engine\output\shadPS4-415907b-patched.exe
     （注意：在 output 子目录里，文件名没有 -v2/-v3/-v4 后缀！）
  ② 一键构建套件     → <GameBox根>\build-engine\build-patched-engine.bat

v2 版产物叫 shadPS4-415907b-patched-v2.exe 且说明让你放 engine\shadps4\ ——
两处都对不上前端检测逻辑，所以体检页永远"未找到"。
另外：光让体检页显示"就绪"还不够——真正生效还必须在版本管理器里勾选！

─────────────────────────────────────────────────────────────
【装回步骤（按顺序做，缺一不可）】
─────────────────────────────────────────────────────────────

第 0 步：下载
  GitHub Actions → 运行页 → Artifacts → 下载 shadPS4-415907b-patched-v4
  （到手是一个 zip，必须先解压！zip 里是 shadPS4-415907b-patched.exe + 两份说明）

第 1 步：复制到引擎目录（游戏运行时要用）
  把 shadPS4-415907b-patched.exe 复制到：
      <GameBox安装目录>\engine\shadps4\
  （与原版 shadPS4-415907b.exe 并排放，不要删除原版！
   这个目录里有 avcodec-61.dll 等运行库，补丁引擎要在这里才能正常启动）

第 2 步：复制到体检页检测目录（让"未找到"变"就绪"）
  把同一个 exe 再复制一份到（没有 output 文件夹就新建一个）：
      <GameBox安装目录>\build-engine\output\shadPS4-415907b-patched.exe
  （文件名必须是这个，不能带 -v2/-v3/-v4 后缀）

第 3 步：版本管理器勾选（真正让游戏用上补丁引擎，最关键！）
  GameBox → 设置 → 版本管理器 → 点「新增自订」
  → 选择 engine\shadps4\shadPS4-415907b-patched.exe → 确认
  → 在已安装列表里勾选它（"使用中"变成补丁引擎）
  没做这一步 = 游戏仍然用原版引擎跑 = 白装！

第 4 步：验证
  ① 设置 → 体检 → 「补丁引擎编译产物」显示"就绪"
  ② 启动游戏打两局（第一局建管线缓存，第二局验证提速），观察：
     机体隐形 / 贴图残影是否改善；第二次启动后是否更快进入流畅状态
  ③ 想深度确认：engine\shadps4\user\logs\ 里检索这些日志行：
       Present mode: mailbox                        → v4 呈现模式最优值生效
       Vulkan PipelineCacheEnabled: 1                → v4 管线缓存默认开
       Preloaded N pipelines                         → 第二次启动起 = 预载入生效
       D16S8 depth format fallback (D24S8) detected  → v2 深度补偿生效
       Occlusion query (ZpassDone) synthesized       → v3 遮挡查询生效
       Conditional rendering active: predicate value → 条件渲染生效+实时值

─────────────────────────────────────────────────────────────
【v4 新增了什么（相对 v3）】
─────────────────────────────────────────────────────────────
  Vulkan 性能优化三项全部出厂默认（不需要手动设置）：
  ① 管线缓存预置：出厂开 + 单 zip 归档。首次运行编译并归档管线，
     之后每次启动预载入全部管线（不再逐管线编译卡顿）；
  ② 呈现模式：出厂默认 Mailbox（三重缓冲：不撕裂+低延迟，弱显卡最优），
     驱动不支持自动回退 Fifo；
  ③ 独显直连：gpu_id 出厂 -1（自动），引擎自动选择本就优先独立显卡，
     Optimus 双显卡笔记本自动用 GTX 960M——与前端图形装置页的手动选择双保险。

【常见问题】
─────────────────────────────────────────────────────────────
Q: 「一键构建套件：未找到」怎么办？
A: 前端检测 <GameBox根>\build-engine\build-patched-engine.bat。主包本来带了这个
   文件夹；如果你在 设置→路径 里把引擎目录改到了别的地方，检测的相对位置也会
   跟着变。把主包里的 build-engine 整个文件夹复制到 GameBox 根目录即可恢复
   （这只是本地编译工具箱，云端编译用户不装也不影响游戏，仅体检页显示问题）。

Q: 勾选补丁引擎后游戏出问题怎么换回来？
A: 设置 → 版本管理器 → 勾选回 shadPS4-415907b.exe（原版一直在，没删）。

Q: 之前下的 v2/v3 产物还能用吗？
A: 能。改名为 shadPS4-415907b-patched.exe 后按上面 1→3 步装即可
   （v2 无遮挡查询修复、v3 无 Vulkan 出厂默认，建议跑本轮 v4）。

Q: 换了显卡驱动后第一次启动变卡了？
A: 正常。管线缓存校验到环境变化会自动重建（日志有 warning 提示），
   第二次启动起恢复预载入加速。
