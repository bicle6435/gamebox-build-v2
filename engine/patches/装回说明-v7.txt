【最简单的装回方式（推荐）】
把 exe 放到 GameBox 文件夹的任意子目录（比如直接放进 build-engine\ 或
engine\shadps4\），然后：
  GameBox 设置 → 体检 → 「📦 一键整理/装回产物」按钮
—— 自动规范命名 + 落位检测位 + 装回引擎目录 + 登记版本管理器 + 选用，
全自动，不用记路径。

【手动装回（两步缺一不可）】
第 1 步：复制 shadPS4-415907b-patched.exe 到两处：
   ① GameBox 文件夹\engine\shadps4\（与原版 shadPS4-415907b.exe 并排，
      不删原版 —— 想切回原版随时可以；v6 引擎也保留并排）
   ② GameBox 文件夹\build-engine\output\（同名，体检页检测用）
      （build-engine\output 文件夹不存在就新建一个）
第 2 步：GameBox 设置 → 体检 → 「⚡ 启用补丁引擎」按钮
      （或 设置 → 版本管理器 → 勾选 shadPS4-415907b-patched.exe）
   ※ 没有第 2 步 = 引擎没换，补丁不生效！

【装回后的验证（1 分钟）】

       Host format fallback: ... using ... instead
     —— 960M 上应出现 D16UnormS8Uint → D24UnormS8Uint = v7 格式阶梯生效
  2. 进对战场景后日志出现（一次性）：
       Polygon offset in use: front_scale=... = v7 诊断日志生效
