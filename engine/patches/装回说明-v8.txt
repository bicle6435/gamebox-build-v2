GameBox v8.0 云编译装回说明（口袋版）
==========================================

【上传（GitHub 网页）】
1. engine/patches/shadps4-gamebox-v8-render-brightness.patch
2. engine/patches/修复补丁说明-v8.md
3. engine/patches/装回说明-v8.txt（本文件）
4. .github/workflows/build-patched-engine.yml（整文件覆盖）
   全部用 Add file → Create new file 粘贴保存。

【编译】
5. Actions → build-patched-engine → Run workflow → 等 1~1.5 小时全绿
6. Artifacts 下载 shadPS4-415907b-patched-v8.zip

【装回】
7. 解压出 shadPS4-415907b-patched.exe
8. 覆盖 GameBox\engine\shadps4\shadPS4-415907b-patched.exe
   （旧文件先改名 .bak 备份）
9. 同时装回 v8 前端更新包（见前端包内说明），两者配套使用

【重要】
- v8 与 v7 补丁互斥：workflow 已移除 v7 的 apply 行。
  仓库里的旧 v7 patch 文件不必删除（已不被引用）。
- 绝对不要用网盘 GameBox-v7.0.zip 里的 .github/engine/patches 重跑 CI
  （那是 v7.0 失败版补丁，必然编译失败——清单红线 8）。
- 游戏目录 custom_configs/CUSA15006.toml 中 patchShaders 必须 = true，
  logEnabled 建议 = true（否则 shad_log.txt 永远是空的，无法体检）。

【启动后自查（30 秒）】
- engine\shadps4\log\shad_log.txt 里搜 "Host format fallback"（应有）
- 搜 "Polygon offset in use"（应有）
- 亮度默认=原版清晰；前端设置页开 "sRGB 输出" 可切回亮版
